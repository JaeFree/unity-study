# unity-study

C#과 Unity를 **빈 파일에서 내 손으로** 짜는 연습 기록입니다. 하루 1시간, 매일 커밋.

## 공부 방법

1. **한국어로 쪼개기**: 코드 전에 할 일을 주석으로 한 줄씩 적는다.
2. **질문으로 바꾸기**: 줄마다 "이걸 어떻게 하지?"를 검색어로 만든다.
3. **조금씩 실행**: 한두 줄 쓰고 바로 Play, `Debug.Log`로 확인한다.
4. **기록**: 막힌 곳 / 찾아본 것 / 새로 안 것.

AI는 답이 아닌 힌트(방향 → 함수 이름 → 한 줄)와 코드 리뷰에만 사용합니다.
