# 혼자 코드 짜기 연습: 1주차

## 왜 읽으면 알겠는데 쓰려면 막힐까

코드를 읽을 때는 "아 이거 본 적 있다"(알아보기)만 하면 되지만, 쓸 때는 머릿속에서 꺼내야(떠올리기) 합니다. 둘은 다른 능력이고, 떠올리기는 **직접 꺼내 보는 연습**으로만 늘어납니다. 그리고 경력자가 코드를 쉽게 짜는 건 문법을 많이 외워서가 아니라 **"할 일을 아주 작게 쪼개는 습관"** 때문입니다. 작게 쪼개면 한 줄 한 줄은 다 아는 것들입니다.

## 집중할 하나

**"빈 C# 파일에서 Unity 스크립트를 내 손으로 완성하기"** 하나만 합니다. C# 책, 알고리즘, CS 이론은 이번 달엔 따로 공부하지 않고, 과제 하다 막힌 문법만 그때그때 찾아봅니다.

## 매 과제마다 하는 4단계

1. **한국어로 쪼개기**: 코드 쓰기 전에, 해야 할 일을 한국어 주석으로 한 줄씩 적는다. 한 줄이 "이걸 어떻게 하지?" 싶으면 더 쪼갠다.
2. **줄마다 질문 하나로 바꾸기**: "키가 눌렸는지 어떻게 알지?", "위치를 어떻게 바꾸지?"처럼. 이 질문이 곧 검색어다.
3. **한 줄 짜고 바로 실행**: 한 번에 다 쓰지 말고, 한두 줄 쓰고 Play 해서 `Debug.Log`로 확인한다.
4. **3줄 기록**: 끝나면 메모장에 "막힌 곳 / 찾아본 것 / 새로 안 것" 3줄.

## AI(나) 쓰는 규칙

- 처음 **15분은 혼자** 버틴다. 검색(Unity 공식 문서, 구글)은 OK.
- 15분 넘게 막히면 나한테 이렇게 물어본다: **"코드 말고 힌트 1단계만"**
  - 1단계: 어떤 방향으로 생각하면 되는지
  - 2단계: 써야 할 Unity 함수/키워드 이름
  - 3단계: 그 한 줄만 (전체 코드는 안 받기)
- 다 짜고 나면 **"리뷰해줘"**로 내 코드 피드백 받기. 이게 제일 많이 늘어요.
- 기존 1~2일차 코드는 과제 **끝난 뒤에** 비교용으로만 연다.

## 0단계: 과제 1 전에 (2~3일, 하루 1시간)

C#/Unity 이해도가 거의 없다면 이것부터. 다 외우는 게 아니라 "이런 게 있다"만 알면 됩니다.

- **C# 최소 5개**: 변수(`int`, `float`, `bool`, `string`), `if`, `for`/`foreach`, 메서드(함수) 만들고 부르기, 클래스와 `public`/`private`
- **Unity 최소 4개**: GameObject와 Component(스크립트도 컴포넌트), `Start`/`Update`가 언제 불리는지, `transform.position`, Inspector에 변수 보이기
- 방법: 빈 스크립트에 `Debug.Log`로 하나씩 찍어보며 확인. 예) `int hp = 10; hp = hp - 3; Debug.Log(hp);`
- 모르는 단어가 나오면 저한테 "OO가 뭐야? 예시 한 줄로"라고 물어보기

## 과제 목록 (쉬운 순, 하루 하나, 30분~1시간)

새 씬(`Practice`)을 하나 만들어 거기서 연습합니다. 본 게임 씬은 건드리지 않아요.

### 과제별 완성 조건

1. **도는 네모**: 네모가 계속 돈다. Inspector에서 회전 속도를 바꾸면 빠르기가 바뀐다. 프레임이 달라도 같은 속도.
2. **움직이는 네모**: 방향키(또는 WASD)를 누르는 동안 그 방향으로 움직이고, 떼면 멈춘다. 속도는 Inspector에서 조절.
3. **Rigidbody2D 이동**: 2번과 같지만 `transform` 대신 `Rigidbody2D`로 움직인다. 대각선이 직선보다 빠르지 않다. 벽(BoxCollider2D)에 막힌다.
4. **카메라**: 플레이어가 움직이면 카메라가 따라간다. 먼저 딱 붙어 따라가게 만들고, 다 되면 부드럽게(`Vector3.Lerp`) 따라가게 바꿔본다. 카메라 z는 -10 유지.
5. **추적하는 적**: 빨간 네모가 플레이어 쪽으로 일정한 속도로 온다. 멀어도 가까워도 속도가 같다.
6. **체력**: 적이 플레이어에 닿으면 플레이어 HP가 1 줄고 Console에 남은 HP가 찍힌다. 0이 되면 플레이어가 사라진다. 다 되면 보너스: 한 번 맞으면 0.5초 동안 안 맞기(무적 시간).
7. **가장 가까운 적**: 씬에 적 5개를 흩어 놓고, 스페이스바를 누르면 플레이어에서 가장 가까운 적 이름이 Console에 찍힌다. 그 적 색을 바꾸면 보너스.

## 과제 1을 4단계로 해보면 (예시)

1단계, 한국어로 쪼개기. 이렇게만 적고 시작하면 됩니다:

```csharp
using UnityEngine;

public class Spinner : MonoBehaviour
{
    // 회전 속도를 Inspector에서 바꿀 수 있는 변수로 만든다 (1초에 몇 도)

    // 매 프레임마다
        // 이번 프레임에 돌 각도 = 속도 × 지난 프레임부터 걸린 시간
        // 그 각도만큼 z축으로 돌린다
}
```

2단계, 질문으로 바꾸기:
- "Inspector에 변수 보이게 하려면?" → `public` 또는 `[SerializeField]`
- "매 프레임마다 실행되는 곳은?" → `Update()`
- "지난 프레임부터 걸린 시간은?" → 검색어: `unity time deltatime`
- "오브젝트를 돌리는 함수는?" → 검색어: `unity transform rotate`

3단계, 주석 아래에 한 줄씩 채우고 Play. 네모(Hierarchy 우클릭 > 2D Object > Sprites > Square)에 스크립트를 붙여 확인합니다.

4단계, 3줄 기록 남기고, 저한테 코드 붙여넣고 "리뷰해줘".
