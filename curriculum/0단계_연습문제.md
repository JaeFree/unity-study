# 0단계 연습문제 (3일, 하루 1시간)

## 준비 (처음 한 번)

1. Unity에서 새 씬 `Practice`를 만든다.
2. Hierarchy 우클릭 > Create Empty, 이름 `Practice`.
3. Project 창에서 스크립트를 만들고(예: `Day0A.cs`), `Practice` 오브젝트에 끌어다 붙인다.
4. 코드는 전부 `void Start() { ... }` 안에 쓰고 Play를 누른 뒤 **Console 창**을 본다.

```csharp
using UnityEngine;

public class Day0A : MonoBehaviour
{
    void Start()
    {
        // 여기에 문제를 푼다
    }
}
```

**규칙**: 문제마다 먼저 한국어 주석으로 할 일을 적고, 그 아래에 코드를 쓴다. 15분 막히면 "0단계 A-3 힌트 1단계만"처럼 물어보기. 답은 일부러 안 적어 뒀어요. 다 풀면 코드를 붙여넣고 "리뷰해줘".

## 1일차: 변수와 if (`Day0A.cs`)

**A-1. 변수 만들고 찍기**
`int` 변수 `hp`에 10, `float` 변수 `speed`에 5.5, `string` 변수 `playerName`에 본인 이름, `bool` 변수 `isAlive`에 true를 넣고 4개 모두 `Debug.Log`로 찍기.
> 확인: Console에 4줄이 나온다. `float`은 숫자 뒤에 `f`가 필요하다는 것도 알게 된다.

**A-2. 값 바꾸기**
`hp`에서 3을 빼고 찍고, 다시 2를 빼고 찍기. 같은 걸 `hp -= 3;` 형태로도 써보기.
> 확인: `7`, `5`

**A-3. 문자열 합치기**
`"재표의 HP: 5"`처럼 이름과 hp를 한 줄로 찍기. `+`로 한 번, `$"..."`(문자열 보간)으로 한 번.

**A-4. if로 판단하기**
`hp`가 0 이하면 `"사망"`, 아니면 `"생존"`을 찍기. `hp` 값을 0, 5, -1로 바꿔가며 Play.

**A-5. if / else if / else**
`hp`가 7 이상이면 `"건강"`, 3 이상이면 `"부상"`, 그 밖에는 `"위험"`. 그리고 `hp <= 0`이면 `isAlive`를 false로 바꾸고 찍기.

## 2일차: 반복문과 메서드 (`Day0B.cs`)

**B-1. for로 세기**
1부터 10까지 찍기. 다음엔 10부터 1까지 거꾸로.

**B-2. 반복하며 데미지**
`hp = 20`에서 시작해, 한 번에 3씩 깎으며 매번 `"남은 HP: ..."` 찍기. HP가 0 이하가 되면 `"사망"` 찍고 멈추기(`break` 또는 조건 이용).

**B-3. 배열과 foreach**
`int[] enemyHps = { 5, 12, 3, 8 };`을 만들고 `foreach`로 하나씩 찍기. 그 다음 **합계**도 구해서 찍기.

**B-4. 가장 작은 값 찾기** (중요! 나중에 "가장 가까운 적 찾기"와 같은 생각)
위 배열에서 가장 작은 값을 찾아 찍기. 힌트 없이 먼저 한국어로 방법을 적어보세요.
> 확인: `3`

**B-5. 메서드 만들기**
`Start` 밖에 메서드 `int TakeDamage(int currentHp, int damage)`를 만들어서, 깎인 HP를 돌려주되 0보다 작아지지 않게 하기. `Start`에서 `TakeDamage(10, 3)`, `TakeDamage(2, 5)`를 불러 찍기.
> 확인: `7`, `0`

## 3일차: 클래스와 Unity 기본

**C-1. Inspector에 변수 보이기** (`Day0C.cs`)
클래스 안(메서드 밖)에 `public int hp = 10;`과 `[SerializeField] private float speed = 3f;`를 만들고, `Start`에서 찍기. Play 전에 Inspector에서 값을 바꾸면 찍히는 값도 바뀌는지 확인.
> 알게 되는 것: 코드에 쓴 값보다 Inspector 값이 우선한다.

**C-2. Start vs Update**
`Start`에 `Debug.Log("Start")`, `Update`에 `Debug.Log("Update " + Time.frameCount)`를 넣고 Play. 몇 번씩 찍히는지 보기. 확인 후 Update 쪽 로그는 지우기.

**C-3. 시간 재기**
`float timer` 변수를 만들고 `Update`에서 `Time.deltaTime`을 계속 더해서, 1초가 지날 때마다 `"1초 지남"` 찍고 timer를 0으로 되돌리기.
> 이게 나중에 "무적 시간", "총알 발사 간격"의 기본이에요.

**C-4. 위치 바꾸기** (Square 오브젝트에 붙이기)
Hierarchy 우클릭 > 2D Object > Sprites > Square. 새 스크립트를 붙여서 `Start`에서 `transform.position`을 찍고, `(3, 2, 0)`으로 옮기기. 그다음 `Update`에서 매 프레임 x를 조금씩 늘려 오른쪽으로 움직이게 하기.

**C-5. 내 클래스 만들기** (`Day0C.cs` 맨 아래, 클래스 밖에)
`MonoBehaviour`를 상속하지 않는 클래스 `Enemy`를 만들기: `string name`, `int hp` 필드와 `void Hit(int damage)` 메서드. `Start`에서 `new Enemy()`로 2마리 만들고 각각 때린 뒤 HP 찍기.
> 알게 되는 것: 클래스 = 설계도, `new` = 실제 물건. 같은 설계도로 만든 2마리는 HP가 따로 논다.
